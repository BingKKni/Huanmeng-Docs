# 翻牌 - 摸金之旅

---

> 深潜数据之海，翻开遗迹中的牌堆。见好就收，还是带着口袋里的战利品继续深入？

**"翻牌 - 摸金之旅"** 是一个探索玩法。
游戏开始后，每一轮操作都会翻开若干物品牌，{blue}翻到任一蓝色及以上品质的物品即可继续翻牌{}，如果某一轮没有翻到符合条件的物品牌，则算作摸金失败：丢失本轮摸到的所有物品，本轮摸金结束；
{red}翻到红色物品{}会立刻带着中途摸到的全部物品撤离，算作撤离成功；
在游戏中途你也可以主动撤离，主动撤离将可以带走你目前为止你摸到的所有物品，同时本轮摸金也将结束，算作撤离成功。

## 如何开始

发送 **/摸金** 打开主菜单，按照按钮指引来开始一局。

::: info
先抽 **运势** 再开始摸金会更有利哦。当天的运势会决定本局的初始运气，部分运势加成也会影响局内运气的变化。
:::

### 入场与体力

开局首轮会同时消耗{blue}体力{}和{gold}50额度{}作为入场费：

- 每局开始摸金会一次性消耗 **60** 点体力。
- 同一局从第二回合开始，每继续一次回合都消耗 **25** 点体力。




若小人类在玩到中途时发现自己体力不足，可以先主动撤离来带走你已经摸到的物品，或等待体力恢复后再继续摸。

## 摸金流程

每轮会随机翻开 **2~5** 张物品牌，并把这些物品放入口袋。每轮结束后，系统根据本轮牌面决定是否能继续：

1. 翻到{red}红色{}物品：立即胜利并强制撤离，口袋内的物品全部带出。
2. 未翻到红色，但至少有一张{blue}蓝色{}或更高品质的物品：可以继续摸金，也可以选择“见好就收”。
3. 本轮没有蓝色及以上物品：本局失败。
4. 若一直深入摸金，到达一定次数后也会自动撤离并带出物品。

### 运气与轮次状态

每局都有独立的运气值。运势会提供开局基础值，牌的品质和词条会让后续轮次的运气上升、下降、重置或获得衰减抵御。

每轮结算面板会显示当前运气、口袋估值，以及下一轮即将生效的词条提醒。遇到“必出蓝”“双倍抽取”“隐藏牌面”等状态时，以面板中的提示为准。

## 撤离与仓库

### 主动撤离与胜利

在游戏中途点击"见好就收"按钮，即可结束当前对局。主动撤离和强制撤离都会视为撤离成功：

- 口袋里的物品会存入摸金仓库，可以拿来卖给酒馆换取额度。
- 局内累积的额度和好感度奖励会在撤离成功时，发放到小人类的达尔文游戏的账户。
- 当小人类首次获得的红色物品时，会自动放到收藏室。只有重复获得红色物品才会进入摸金仓库。

### 失败

若某一轮未翻到蓝色及以上物品且未被局内的道具词条 *挽救*，将算作摸金失败。口袋中的物品全部丢失 —— 不过会为小人类保留{blue}一件当日价值最高的物品{}。

### 酒馆回收

仓库里的物品可以按当天价格出售：

- **/摸金口袋**: 查看口袋、仓库库存。
- **/酒馆回收 <物品名> [数量]**: 出售指定物品。
- **/一键回收**: 出售仓库内全部物品{red}（神话物品除外）{}。

{red}妈妈的便当{} 和 {red}两套公式服{} 道具不能交给酒馆回收。
单次一键回收额达到 **300** 额度时，酒馆还会额外赠送给小人类一些礼品。

## 收藏室

红色物品首次带出时会自动入藏，并获得 **1** 梦晶奖励。收藏室会记录红色物品图鉴和五个收藏系列的收集进度：尖端科技、人类群星闪耀系列、各地美食系列、化学魅力时刻、发烧友系列。

部分金色物品也具有收藏价值。可用 **/收藏室 存入 <物品名>** 将它们从仓库陈列到收藏室；重复的收藏品可使用 **/收藏室 填充 <物品名> [数量]** 转化为收藏价值，提升收藏室等级，最高为 **Lv.8**。

## 摸金会刷屏吗？

会，而且会比旧版翻牌玩法更加严重，幻梦作者强烈推荐小人类私信去摸金，避免群内游玩打扰到其他人聊天哦。

背包等级达到 **7** 级后，可在 **/摸金设置 防刷屏模式** 中开启防刷屏模式。开启后可减少刷屏影响。
