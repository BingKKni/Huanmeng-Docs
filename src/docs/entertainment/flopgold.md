# 翻牌 - 摸金之旅

---

> 深潜数据之海，翻开遗迹中的牌堆。见好就收，还是带着口袋里的战利品继续深入？

**"翻牌 - 摸金之旅"** 是一个探索玩法。
游戏开始后，每一轮操作都会翻开若干卡牌，{blue}翻到任一稀有蓝色及以上品质的物品即可继续翻牌{}；若没有符合条件的物品且未被局内效果挽救，则摸金失败，仅保留口袋中当日估值最高的一件物品。
普通难度下，{red}翻到红色物品{}会立即带着全部战利品撤离，也可以在中途主动“见好就收”。
**机密难度**还会遇到事件卡、道具卡与“机会”和“命运”；红色神话物品不会触发自动撤离，主动撤离也需要等待正确路线确认才能走。

## 如何开始

发送 **/摸金** 打开主菜单，按照按钮指引来开始一局。

::: info
先抽 **运势** 再开始摸金会更有利哦。当天的运势会决定本局的初始运气，部分运势加成也会影响局内运气的变化。
:::

### 入场与体力

每次开局都会消耗一定的额度作为入场费；开局体力会随当天的开局次数递增：

| 地图 | 入场费收取 | 入场体力消耗 | 中途体力消耗 |
| :--: | :--: | :--: | :--: |
| 普通 | 50额度 | 60/70/80 | 15 |
| 机密 | ~~158额度~~（限时128） | 80/100/110 | 20 |

- 以普通地图为例，当天首局消耗 **60** 点体力，第二局消耗 **70** 点，第三局起每局消耗 **80** 点。两种地图分别计数，次日重置。
- 以普通地图为例，同一局从第二回合开始，每继续一次回合都消耗 **15** 点体力。局内效果可能改变实际消耗。

::: info
机密有专属的入场券道具，不定时通过活动发放，可抵扣一局的基础入场费，额外购买的入场加成仍需支付额度。
绝密地图暂未开放。
:::
若小人类在中途发现体力不足，可以等待体力恢复后再继续摸。普通难度可以选择主动撤离，机密难度则建议提前预留体力。

## 摸金流程

普通难度每轮随机翻开 **2~5张** 物品牌，获得的物品将直接放入口袋。
机密难度每轮先展示若干可选牌，点击物品卡会翻出一批物品，点击其他卡牌则会出现对应卡牌类型的事件。无论如何，在进入下一轮前，都需要先翻开物品卡。

翻出物品后，幻梦会根据牌面决定是否能继续摸金：

1. 本轮至少有一张{blue}蓝色{}或更高品质的物品：可以继续摸金，也可以申请撤离。
2. 本轮没有蓝色及以上物品且未被局内效果挽救：本局失败。
3. 普通难度翻到{red}红色{}物品时立即胜利并强制撤离，机密难度需按撤离规则“申请”撤离。
4. 若一直深入摸金，到达一定次数后也会自动撤离并带出物品。

### 运气与轮次状态

每局都有独立的运气值。运势会提供开局基础值，牌的品质和词条会让后续轮次的运气上升、下降、重置或获得衰减抵御。

每轮结算面板会显示当前运气、口袋估值，以及下一轮即将生效的词条提醒。遇到“必出蓝”“双倍抽取”“隐藏牌面”等状态时，以面板中的提示为准。

## 机密难度


机密有更多事件与局内状态，让探索有了新的选择。目前选择机密场地需要收藏室达到 **Lv.3**。

### 入场加成

进入机密时，可以额外消耗额度购买本局加成：

| 加成 | 价格 | 效果 |
| :--: | :--: | :-- |
| 饮料 | 10额度 | 前3轮每轮多翻1张牌 |
| 制式券 | 20额度 | 本局初始运气 +18.88% |
| 通行证 | 20额度 | 触发局内小游戏时，有50%概率直接通过，限2次 |
| 高级通行证 | 40额度 | 触发局内小游戏时，有100%概率直接通过，限2次 |

通行证与高级通行证**不能同时购买**。

### 五种卡牌

每轮提供 **3~5张** 可选卡牌，其中包含物品卡必翻卡牌。

| 类型 | 作用 |
| :--: | :-- |
| 物品卡 | 翻出一批物品 |
| 事件卡 | 遇到剧情、两个选择或独有小游戏 |
| 道具卡 | 获得局内状态，可能有利，也可能带来负担 |
| 机会 | 遇到一段随机际遇，可能收获奖励，也可能付出代价 |
| 命运 | 遇到另一类随机际遇，同样有得有失 |

“机会”和“命运”可能影响额度、好感度、运气、物品、体力或撤离进度，也可能改变后续小游戏与选路状态。具体结果幻梦就留待小人类在局内发现啦~

### 事件与小游戏

可能遇到林中的老奶奶、好奇的小孩、询问梦境的老人，也可能发现自动贩卖机、拾荒者或愿意带你离开的旅人。部分事件会随季节或活动更换。

不同选择可能消耗额度、道具或物品，也可能带来奖励、负面状态，甚至直接结束本局。**剧情事件不保证安全**，请留意按钮与现场提示；问题答案和隐藏结果幻梦将留给小人类自己探索~

局内小游戏共有五类：

| 玩法 | 操作 | 初始限时 |
| :--: | :-- | :--: |
| 顺序点击 | 在3×5按钮中按顺序点击数字1~15 | 10秒 |
| 点亮按钮 | 在5×5按钮中点亮所有未亮按钮，重复点击已亮按钮会失败 | 15秒 |
| 记忆暗号 | 记住提示文本，等待按钮出现后点中对应文本 | 3秒 |
| 颜色筛选 | 在5×5按钮中按提示选择符合条件的按钮 | 10秒 |
| 数字筛选 | 在3×5按钮中选出符合大小、奇偶或质数等条件的数字 | 10秒 |

常规小游戏成功时，可获得 **1件物品**与额度奖励。初始限时内的额度奖励为 **8~15**，超时后会衰减，达到最终时限则失败。

::: info
常规小游戏失败或超时只会让**该张事件卡作废**，不会直接摸金失败，故小人类仍可探索本轮剩余卡牌。
:::

### 机密撤离

机密中，{red}摸到红色物品不会自动撤离{}。点击“发起撤离”后，需要等待路线确认，**所以不是按下就能走人的哦**。

等待越久，撤离成功的机会越高。撤离尚未成功时，小人类仍需正常翻牌。若途中摸金失败，照样按失败规则结算。

此外，有些事件可以在支付额度、提交物品或满足条件后撤离，也有少见的直接撤离机会。是否付出代价、是否继续深入，由小人类决定。

## 撤离与仓库

### 主动撤离与胜利

普通难度中途点击“见好就收”即可结束对局；机密难度需等待撤离判定成功，或通过撤离事件离场。主动撤离和强制撤离成功后，通常按以下规则结算；事件另有代价或折损时，以事件提示为准：

- 口袋里的物品会存入摸金仓库，可以拿来卖给酒馆换取额度。
- 局内累积的额度和好感度奖励会在撤离成功时，发放到小人类的达尔文游戏的账户。
- 当小人类首次获得红色物品时，会自动放到收藏室。只有重复获得红色物品才会进入摸金仓库。
- 机密中记下的保险箱道具需成功撤离后领取，每局最多带出 **2件**。

### 失败

若某一轮未翻到蓝色及以上物品且未被局内效果挽救，将算作摸金失败。口袋中仅保留{blue}一件当日价值最高的物品{}，其余物品则会丢失。

### 酒馆回收

仓库里的物品可以按当天价格出售：

- **/摸金口袋**: 查看口袋、仓库库存。
- **/酒馆回收 <物品名> [数量]**: 出售指定物品。
- **/一键回收**: 出售仓库内全部物品{red}（神话物品除外）{}。

{red}妈妈的便当{} 和 {red}两套公式服{} 道具不能交给酒馆回收。
单次一键回收额达到 **300** 额度时，酒馆还会额外赠送给小人类一些礼品。

### 共享负重

摸金仓库与保险箱共用负重上限，当前负重可在 **/摸金口袋** 或酒馆回收页面查看。只有仓库中的物品会计入摸金负重，局内口袋和收藏室展柜不占用负重。

## 收藏室

红色物品首次带出时会自动入藏，并获得 **1** 梦晶奖励。收藏室会记录红色物品图鉴和五个收藏系列的收集进度：尖端科技、人类群星闪耀系列、各地美食系列、化学魅力时刻、发烧友系列。

部分金色物品也具有收藏价值。可用 **/收藏室 存入 <物品名>** 将它们从仓库陈列到收藏室。
可使用仓库中的物品填充收藏室价值。填充会消耗物品，建议先将想保留的藏品存入展柜。

## 摸金会刷屏吗？

会，而且会比旧版翻牌玩法更加严重，幻梦作者强烈推荐小人类私信去摸金，避免群内游玩打扰到其他人聊天哦。

背包等级达到 **7** 级后，可在 **/摸金设置 防刷屏模式** 中开启防刷屏模式。开启后可减少刷屏影响。
