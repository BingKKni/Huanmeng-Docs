# 常见问题

## 查出来的数据不准？
幻梦只看布吉岛的数据，而不看是怎么来的。所以数据有错误的情况下，一般不是幻梦的问题。
布吉岛和幻梦均无法保证小人类查询到的数据是一定准确的，故仅供参考。
其次，请检查幻梦返回的数据中，是否包含了这段文本：

![TTL示例截图](/img/bugland/ttl.png){.hm-center-img width="400"}

如果包含了这段文本，那就需要等待对应时间，让数据刷新一次之后再查询。
请不要听信所谓"幻梦查的不准，要用XXX查"等谣言。

## 我明明玩了布吉岛一段时间了，但查不出来我的数据？
请根据以下方式逐一排查：
1. 如果你的账号是当天注册并游玩了一段时间，那么请明天再查询。
2. 如果你的账号之前就注册并游玩了一段时间，请尝试在布吉岛服务器里游玩几局游戏让数据刷新出来{gray}（一般数据刷新延迟为6小时）{}，再试试能否查到。
3. 请检查你给幻梦的ID大小写是否正确，大小写不正确很可能会影响到最终查询结果。
4. 请检查你给幻梦的ID是否完全打入，比如你的ID是 **\_\_小布丁\_\_**，但你给幻梦的ID却是 **小布丁**{gray}（少了下划线）{}，提供不完整的ID就有可能查不到数据。

## 幻梦提示我该ID无法查询？

![ID无法查询示例截图](/img/bugland/id_banned.png){.hm-center-img width="400"}

有以下原因：
- ID被安全策略打击，请检查游戏ID是否包含敏感词（比如涉及外挂、黄赌毒、其他不宜内容等）
- ID的持有者曾经违反了幻梦使用守则，该情况我们无法解除

## 能不能新加一个如记忆速建或其他玩法的查询？
你可通过**游戏内反馈功能**向布吉岛官方提出相应建议。
你也可以向我们提出这些建议，我们也会在评估后向布吉岛官方主动推进。
