# 指令列表

这里列出了布吉岛查榜功能的所有指令，小人类可以通过这些指令来查询你想要的数据哦。

## 绑定ID
> 指令: **/bjd 绑定**

::: info
如果要绑定新的ID，就再次输入一遍该指令即可，会自动替换掉原先绑定的旧ID。
:::
绑定自己的ID，这样在查询大部分数据的时候，就不用再手打一遍自己的ID了。

## 查询个人基本信息数据
> 指令: **/bjd player** 或 **/bjd 玩家**

用于查询指定ID在布吉岛内的基本信息。
可查询到的有：
- 布吉岛大厅等级
- 起床等阶
- 空岛等阶
- 村守等阶
- 加入的公会

要求玩家在14天内登录过布吉岛。

## 查询指定的玩法数据
> 指令: **/bjd name**

用于查询指定ID在布吉岛的一个玩法内的数据。
目前支持查询的有：
- 起床战争
- 空岛战争
- 村庄守卫战
- 竞技场
- 逃离暗区
- 职业大乱斗（职业战争）
- 极饿游戏（饥饿游戏）

查询后返回该玩法内的所有数据。

## 查询玩家上榜数据
> 指令: **/bjd top** 或 **/bjd 排行榜**

用于查询玩家在哪些玩法内上榜了，以及上榜的数量。
查询后返回玩家的上榜数据。

## 列出排行榜
> 指令: **/bjd toplist**

::: info
该指令推荐在私信环境内使用，群里用容易刷屏。
:::

用于列出一个玩法的排行榜数据，支持分玩法（起床、空岛等）、分模式、分时间（日榜、周榜、年榜、总榜）、分平台（Java或基岩版）。
也支持导出一个玩法的排行榜内的所有排名至一张图里，但由于导出所消耗的性能较多，故每日可导出的次数有上限。

## 查询公会数据
> 指令: **/bjd guild**

用于查询一个公会的基本信息。
查询后返回公会名称、公会等级、成员规模、是否公开加入、在线成员等信息。

## 查询近期游玩数据
> 指令: **/bjd recent**

用于查询玩家在近期游玩过的玩法数据。
目前支持的玩法：起床战争、空岛战争、核心战争、极饿游戏（饥饿游戏）和村庄守卫战。

## 查询对局数据
> 指令: **/bjd match**（在 **/bjd recent** 内）

在 **/bjd recent** 内，点击蓝色文字可以查询到该场对局的详细信息。

这将返回该对局的详细信息，包括对局时间、对局模式、对局结果、对局时长、对局人数、对局玩家等。

## 查询成就生涯数据
> 指令: **/bjd 成就** 或 **/bjd achievement** 或 **/bjd ache**

这将返回玩家在指定玩法内的成就生涯数据，包括达成的成就数量、成就点数等。

## 查询2025年度总结数据
> 指令: **/bjd 2025**

这将返回玩家在2025年内的游玩总结数据。

## 查询个人分析（六边形）数据
> 指令: **/bjd a bw**（目前只支持起床战争）

这将查询并分析玩家在**起床战争**内的数据，返回六边形图。

## 个性化你的查榜UI图
> 指令: **/布吉岛排版**

::: info
只在 /bjd name 内生效。
:::
这将列出排版设置，你可以在设置中调整头像皮肤、昵称颜色、图片清晰度等。

## 个性化你的对局详情UI图
> 指令: **/历史数据排版**

::: info
只在 /bjd match 内生效。
:::
这将列出历史数据排版设置，你可以在设置中调整排版结构、显示的纹理，以及是否显示详细数据等。
