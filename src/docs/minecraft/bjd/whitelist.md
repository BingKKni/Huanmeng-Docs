# ID白名单

出于隐私保护和平台安全规则的考虑，幻梦默认不对所有人显示完整ID。
如果小人类想要让幻梦完整显示你的ID，请私信或在群内@幻梦发送 **"白名单"** 三个字，然后按照操作指引完成申请。

![ID白名单](/img/bugland/id_whitelist.png){.hm-center-img width="400"}

**以下类型ID不支持申请白名单，请谅解：**
- 包含外挂词汇的ID
- 包含推广（如联系方式）的ID
- 包含辱骂词汇的ID
- 包含涉黄、性暗示词汇的ID
- 包含政治敏感词汇的ID
- 包含真实信息（如真实姓名、身份证号等）的ID
- 其他我们认为不适宜展示的ID

::: info
申请ID白名单后，幻梦协管或开发者会审核你的ID是否合规，审核通过后即可永久显示完整ID。审核时间一般在0至2天内，如果审核同学较忙，则审核时间可能还会相应延长，最长不会超过14天。
:::
::: danger
严禁申请违规敏感ID，违规者将被永久封禁使用幻梦。
:::
