# 福利活动

## 面向主播 & 创作者

如果你是一名主播，且正在直播布吉岛相关内容，或是一名视频创作者，在视频网站上发布了布吉岛相关的视频，则有机会向我们申请主播相关权益！

**我们愿意给你：**
- 在每一次查询布吉岛数据时，所有玩家昵称都将对你完整展示，这样你可以很方便的去对比一些人的游戏数据；
- 解锁布吉岛UI个性化设置里面的所有投喂者权益，如自定义颜色昵称、自定义展示什么皮肤等；
- 获得幻梦开发组的合作机会，我们会根据你提出的意见（如有）来改进幻梦对每个人的使用体验。你也将有机会提前体验到幻梦的新功能。

| | 主播 | 荣誉主播 | 创作者 |
| ---: |:----:|:----:|:----:|
| 查榜所有昵称完整展示 | ❌ | ✅ | ❌ |
| 自定义颜色昵称 | ✅ | ✅ | ✅ |
| 自定义展示皮肤 | ✅ | ✅ | ✅ |
| 调整图片生成清晰度 | ✅ | ✅ | ✅ |
| 部分功能的每天可用次数 | 提升 | 提升 | 提升 |
| 提前体验到新功能 | ✅ | ✅ | ✅ |
| 获得幻梦开发组的合作机会 | ✅ | ✅ | ✅ |
> 为防止滥用，目前【查榜所有昵称完整展示】权益仅对荣誉主播以及我们受信任的主播 & 创作者开放。 

**申请条件：**
- 使用幻梦的过程中，没有违反过我们[用户准则](/about/rule/user?from=bjd_creator)的任意一条规则；
- 在布吉岛内含有 **主播**、**荣誉主播**、**创作者** 任一身份标识；
- 近一周，发布过至少一条含幻梦查榜图元素的视频（可以是视频中间插入、评论置顶插入、封面插入等）。没有发布过相关视频也可以先提前申请权益，但后续一定要发布哦；
- 准备好相关截图（创作后台、游戏截图等）证明自己是本人。
