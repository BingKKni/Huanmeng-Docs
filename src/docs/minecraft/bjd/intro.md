# 使用教程

本篇文档将详细介绍如何在幻梦上使用布吉岛查榜功能

## 第一步：私信幻梦

首先在QQ首页中，搜索幻梦，选择网络搜索。在机器人列表中点击第一个"幻梦"，再点击右下角的"添加使用"（发消息）按钮即可进入到私信界面。
如果你群里有幻梦，则点击幻梦头像 -> "添加使用"（发消息）也可以进入到私信界面。

## 第三步：尝试为自己查询服务器内的基本信息

点击第一个按钮，幻梦会自动将指令前缀文本填充到你的输入框中，你只需在后面输入自己的游戏ID，然后发送，即可查询到自己在服务器内的基本信息啦。

![点击基本信息按钮](/img/bugland/click_player_data_button.png){.hm-center-img width="400"} ![在后方打入游戏ID](/img/bugland/input_self_player_name.png){.hm-center-img width="400"} ![查询结果](/img/bugland/query_self_player_data_result.png){.hm-center-img width="400"}

**如果这一步幻梦回复你说查询不到该玩家的数据，请小人类按照下列的指引检查：**
- 输入的游戏ID是否正确？ID是要完整的噢，包括下划线符号这些都要打进去，不能只打一部分
- 游戏ID是指游戏大厅内右侧计分板显示的ID，以它为准。不是启动器ID哦
- 近期有没有登录过游戏？如果超过14天没登录，那数据就查不到了。去登录一下布吉岛服务器，然后等大概2-5分钟就能查到了

**如果成功查到了，恭喜你，你超过了99%幻梦用户！接下来推荐几个实用的操作：**
- 在查榜主菜单中点击更多按钮，来看看还能查哪些数据
- 绑定自己的ID，绑定后就不用每次查的时候都输ID了，直接发送查榜指令就能查询
