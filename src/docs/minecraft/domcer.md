# DoMCer查榜帮助文档

这里列出了DoMCer查榜功能的所有指令，小人类可以查询玩家基本信息、公会和多个玩法的数据。

## 怎么使用

私信幻梦或在有幻梦的群聊中发送 **/我的世界菜单**，再点击“DoMCer”即可进入查榜功能。
你也可以直接发送带有玩家ID的指令，例如：

> 指令: **/d profile Sym_k**

如果查询成功，幻梦会返回对应数据，并提供“再查一个”按钮。

## 绑定ID
> 指令: **/d 绑定 游戏ID**

绑定自己的DoMCer ID后，大部分查询都可以省略指令末尾的ID。例如绑定后发送 **/d bw**，就会查询你自己的起床战争数据。

::: info
如果要绑定新的ID，就再次输入一遍该指令即可，会自动替换掉原先绑定的旧ID。
:::
## 查询玩家基本信息
> 指令: **/d profile 游戏ID**

用于查询指定玩家的：
- DoMCer等级
- 会员等级
- 街机硬币

## 查询玩家所在的公会信息
> 指令: **/d guild 游戏ID**

通过一个玩家的ID查询其所在公会的信息。这个指令不能直接使用公会名称查询。

## 查询起床战争
> 指令: **/d bw 游戏ID**

用于查询一名玩家的起床战争数据。

## 查询极限生存
> 指令: **/d uhc 游戏ID**

用于查询一名玩家的极限生存数据。

## 查询搭路练习
> 指令: **/d bridge 游戏ID**

用于查询一名玩家的搭路练习数据。

## 指令列表

|功能|带ID查询|查询已绑定ID|
|:-:|:-:|:-:|
|基本信息|**/d profile 游戏ID**|**/d profile**|
|公会信息|**/d guild 游戏ID**|**/d guild**|
|起床战争|**/d bw 游戏ID**|**/d bw**|
|极限生存|**/d uhc 游戏ID**|**/d uhc**|
|搭路练习|**/d bridge 游戏ID**|**/d bridge**|

## 查询服务器状态
> 指令: **/mc DoMCer**

用于查询DoMCer当前的在线人数、人数上限、服务器版本和连接延迟。也可以发送 **/在线人数**，在幻梦支持的多个服务器中查看DoMCer的在线情况。

## 常见问题

### 幻梦提示“缺少要查询的ID”？

那是因为小人类没有在指令后输入自己的ID。请补全ID，或先使用 **/d 绑定 游戏ID** 完成绑定后再查询~

### “玩家不存在或未上榜”是什么意思？

字面意思。请先检查ID是否完整、大小写是否正确哦。

### 为什么查询公会时提示玩家没有加入公会？

字面意思。这代表玩家没有加入任何公会。
