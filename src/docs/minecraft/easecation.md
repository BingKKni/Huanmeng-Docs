# EaseCation查榜帮助文档

幻梦可以查询玩家在EaseCation当前排行榜中的上榜数据，包括排名、上榜项目和分数。

::: info
EaseCation目前提供的接口较为残缺，EC官方将部分接口进行了私有化，并且没有对我们提供接口文档。我们欢迎各位小伙伴向EC官方提出开放建议，让幻梦能够早日适配EC完整接口。
:::
## 怎么使用

私信幻梦或在有幻梦的群聊中发送 **/我的世界菜单**，再点击“EaseCation”即可进入主界面。

## 绑定ID
> 指令: **/ec 绑定 玩家昵称**

绑定自己的EaseCation昵称后，可以直接发送 **/ec top** 查询自己的上榜数据，不需要每次重新输入昵称。

::: info
如果要绑定新的昵称，再次输入一遍该指令即可，会自动替换原先绑定的昵称。
:::
## 查询上榜数据
> 指令: **/ec top 玩家昵称**

这将返回你在某个玩法排行榜中的上榜数据：
- 排名
- 上榜项目
- 分数

## 查询服务器状态
> 指令: **/mc EaseCation**

用于查询EaseCation当前的在线人数、人数上限、服务器版本和连接延迟。也可以发送 **/在线人数**，在幻梦支持的多个服务器中查看EaseCation的在线情况。

## 常见问题

### 为什么提示排行榜可能正在维护？

这是因为EC接口返回了空数据、异常结构或失败状态，幻梦无法完成解析，等待EC恢复排行榜功能后再试一次即可。
