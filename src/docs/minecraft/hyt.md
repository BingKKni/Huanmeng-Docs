# 花雨庭查榜帮助文档

::: warning
我们不再会为花雨庭服务器查榜提供新的功能更新，仅对现有的功能进行基本维护。
数据现在用的是关服前保存的最后一刻数据（每个玩法排名500名内的玩家）以及幻梦自身缓存的历史数据。通常只有在2021年至2024年期间使用幻梦查询过的玩家，才能在现在查到自己的数据。
:::
## 怎么使用

私信幻梦或在有幻梦的群聊中发送 **/我的世界菜单**，再点击“花雨庭”即可进入主界面。
你也可以直接发送 **/hyt** 打开花雨庭查榜菜单，然后选择要查询的玩法，在指令后方输入完整的游戏ID并发送。

例如要查询玩家 **小布丁qwq** 的起床战争数据，可以发送：

> 指令: **/hyt bw 小布丁qwq**

需要确认大小写、中文、数字和下划线等内容完整且正确。

## 绑定ID
> 指令: **/hyt 绑定 游戏ID**

绑定自己的ID后，查询普通玩法数据时可以不再重复输入ID。例如绑定后直接发送 **/hyt bw**，就会查询你绑定的账号。

::: info
如需换绑，再次发送 **/hyt 绑定 新游戏ID** 即可，幻梦会自动替换原先绑定的ID。
:::
## 查询玩法数据

### 起床战争
> 指令: **/hyt bw 游戏ID**

用于查询一名玩家的起床战争历史数据，支持评分。

### 无限火力
> 指令: **/hyt bwxp 游戏ID**

用于查询一名玩家的起床战争·无限火力的历史数据，支持评分。

### 空岛战争
> 指令: **/hyt sw 游戏ID**

用于查询一名玩家的空岛战争历史数据，支持评分。

### 职业战争
> 指令: **/hyt kb 游戏ID**

用于查询一名玩家的职业战争历史数据，支持评分。

### 狼人杀
> 指令: **/hyt ww 游戏ID**

用于查询一名玩家的狼人杀历史数据。

## 通过排名查询玩家

如果想看看历史排行榜中某个名次的玩家，可以使用下面的指令：

|玩法|指令|
|:-:|:-:|
|起床战争|**/hyt bwr 排名**|
|无限火力|**/hyt bwxpr 排名**|
|空岛战争|**/hyt swr 排名**|
|职业战争|**/hyt kbr 排名**|
|狼人杀|**/hyt wwr 排名**|

<!-- hm-table: center -->

排名必须是1至500之间的数字。例如发送 **/hyt bwr 1**，即可查询起床战争历史排行榜第1名的数据。

## 查询个人分析

### 起床战争分析
> 指令: **/hyt bwa 游戏ID**

幻梦会根据历史数据生成个人分析图，展示突进、发育、生存、射手、人头和K/D能力值。

### 空岛战争分析
> 指令: **/hyt swa 游戏ID**

幻梦会根据历史数据生成个人分析图，展示综合、生存、射手、人头和K/D能力值。

## 常见问题

### 为什么绑定成功了，还是查不到数据？

花雨庭已经停服，幻梦无法重新获取或补录战绩。如果这个ID过去没有在幻梦上查询过，就没办法了。

### 为什么数据一直没有变化？

大脑过载：花雨庭关闭后就不可能再会有新的对局，故数据也就不会刷新了..！

### 为什么我输入了正确的ID仍然查不到？

请依次检查：
1. ID是否完整，大小写是否与当时使用的游戏ID完全一致。
2. ID是否包含了遗漏的中文、数字或下划线。
3. 该ID是否曾在2021年至2024年期间通过幻梦查询并被保存。
4. 查询指令是否与玩法对应。

::: info
幻梦自花雨庭而生，而成长。虽然花雨庭已经关闭，但幻梦会继续陪伴小人类，见证小人类在其他服务器或新服中的成长。我们随时欢迎小人类时不时回头看一遍自己曾经打过的数据。
:::
