# Hypixel查榜帮助文档

幻梦支持查询Hypixel玩家的基本信息、SkyBlock（空岛生存）和多个小游戏数据。当前功能仍在开发测试中，查询结果仅供参考。

## 怎么使用

私信幻梦或在有幻梦的群聊中发送 **/我的世界菜单**，再点击“Hypixel”即可进入主界面。

## 绑定ID
> 指令: **/hyp bind 游戏ID**

绑定自己的Hypixel ID后，在查询大部分玩法数据时，后面就不用再打一次自己的ID啦。
若要绑定新的ID，就再次输入一遍该指令即可，会自动替换掉原先绑定的旧ID。

## 查询基本信息
> 指令: **/hyp player 游戏ID**

用于查询玩家的Rank、Hypixel等级、当前等级经验进度、人品值、成就点数、语言设置、首次和上次登录时间、客户端版本、最近游玩的游戏及在线状态。

## SkyBlock 查询说明
> 指令: **/hyp skb 游戏ID**

幻梦会优先读取玩家当前选中的SkyBlock存档；如果没有明确选中的存档，则默认会读取第一个存档。
查询结果包括：
- 硬币和银行存款
- 当前游玩模式和携带的宠物
- Combat、Mining、Farming、Fishing、Enchanting、Alchemy、Taming 等级
- Dungeon 等级。包括 Healer、Mage、Berserk、Archer 和 Tank 等级
- Zombie、Spider、Wolf、Enderman(Zealot)、Blaze 和 Vampire Slayer 等级
- Fairy Souls、Bestiary、Magic Power、Collections 和 Pets 的解锁数量

由于 SkyBlock 暂时没有官方简体中文翻译，故图片内显示的中文翻译仅供方便理解。若有翻译错误，欢迎向我们反馈~

::: info
如果玩家关闭了 SkyBlock 中的 Skills、Dungeon、Bestiary 或 Bank 任一 API，相应数据会显示为“隐藏”。这是玩家的API隐私设置，并非幻梦查询出错。
:::
## 查询服务器状态
> 指令: **/mc Hypixel**

用于查询Hypixel当前的在线人数、人数上限、服务器版本和连接延迟。由于需要连接国外服务器，查询可能比其他服务器更慢。

## 常见问题

### 幻梦提示ID格式不正确？

请确认ID长度符合 Minecraft 的昵称长度规则。由于 Hypixel 为国际版服务器，不支持中文昵称注册和查询。

### “玩家不存在”和“未能查询到数据”有什么区别？

“玩家不存在”通常表示没有找到对应的 Java 正版玩家；“未能查询到数据”表示玩家存在，但没有游玩过该玩法、没有 SkyBlock 存档，或没有足够的数据可供展示。

### 为什么数据不实时刷新？

为了减少重复请求（Hypixel 要求），相应的数据会做1-2分钟的缓存。

### 为什么显示“幻梦在生成图片的时候出错了”？

请稍后再试指令。如果持续发生，可以点击返回消息下方的“报告问题”按钮反馈给我们。
