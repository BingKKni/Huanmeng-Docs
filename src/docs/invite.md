# 🎁 呼朋唤友 · 邀请幻梦有礼

### 呼朋唤友是什么？
这是一个**常驻活动**：小人类把幻梦邀请到新的群聊，群里的小伙伴玩起来之后，你就能一路获得 **额度** 奖励，还有专属 **称号** 可以拿！

参与方式非常简单：把幻梦邀请进一个新群，奖励自动开始计算，{green}**无需报名、无需指令**{}。邀请后在聊天中发送 `/邀请` 就能随时查看自己的进度。

::: tip
邀请前记得先和群主或管理员打个招呼，避免不知情引起不必要的误会哦~
:::

### 奖励怎么拿？
每个被邀请的群都有一条属于自己的「奖励之路」，一共四个里程碑，达成一个发一笔：

<!-- hm-table: smart; widths=7em,auto,6em,9em; min=34em -->
| 里程碑 | 达成条件 | 奖励额度 | 发放时间 |
| :-: | :- | :-: | :-: |
| {bg-green}🌱 邀请成功{} | 把幻梦邀请进一个新群 | {green}+8.88{} | 立即到账 |
| {bg-cyan}❄️ 破冰{} | 邀请后的 **7 天内** ，群里有**3 位**小伙伴使用过幻梦指令 | {green}+15.88{} | 立即到账 |
| {bg-orange}🏡 扎根{} | 邀请后的 **14 天内** ，群里有**5 位**小伙伴使用过 | {green}+24.88{} | 次日0点结算 |
| {bg-gold}🌟 常驻{} | 邀请后的 **30 天内** ，群里有**8 位**小伙伴使用过 | {green}+38.88{} | 次日0点结算 |

### 如何计算有几个"小伙伴"使用过幻梦的指令？

- 在群里**使用过任意一条幻梦指令**的用户就算一位小伙伴；同一个人不管用多少次、多少天，都只算 **1位**。
- **邀请人自己不计入** —— 所以达成条件时需要的是你之外的 3 位小伙伴参与。
- 机器人账号不计入。
- 同一位小伙伴出现在你邀请的多个群里时，只在 TA **最先使用幻梦的那个群**计数，其他群不重复计算。{gray}（不同邀请人之间互不影响）{}

### 哪些情况会停止奖励？

幻梦被移出群聊后，该群还没达成的里程碑会**立刻停止结算**。已经到手的额度{green}**不会被扣回**{}。被移出后再把幻梦拉回来，里程碑不会重新开始计算，也不会产生新的奖励。

### 滥用保护

如果你近 **30 天**邀请的群数 ≥ **5 个**，且其中幻梦被移出的比例 ≥ **60%**，那么你的新邀请将暂时不计入活动。当比例回落后会自动恢复。

正常分享给朋友群的小人类完全不用担心这条规则，本条规则只针对批量拉群刷奖励的行为。
同时，我们也会不定期筛查日志，如果我们发现有人滥用该活动批量刷取额度的，将根据违规程度给予惩罚，包括但不限于: 回收奖励、终止资格、封禁账号等。

| :-: | :-: |

| 🎉呼朋唤友·3 | 累计 3 个群破冰 |
| 🏆呼朋唤友·10 | 累计 10 个群破冰 |

获得后发送 `/称号` 即可佩戴展示。{gray}（更高级的称号将在未来版本内推出，敬请期待）{}

### 常用指令
- **/邀请** —— 活动主页，查看自己的邀请战绩和奖励进度
- **/邀请 记录** —— 查看每一个邀请群的详细状态
- **/邀请 规则** —— 在聊天里查看规则摘要

### 奖励有上限吗？
本活动目前暂无每日或每月的奖励上限。
