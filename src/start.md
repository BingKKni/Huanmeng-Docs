## 幻梦支持添加到哪里？

幻梦支持添加到QQ群、QQ频道供小伙伴们一起游玩，也可支持私信游玩。

| | QQ群 | QQ频道 | 消息列表 | 频道私信 |
|-:|:----:|:----:|:----:|:----:|
| 支持添加 | ✅ | ✅ | ✅ | ✅ |
| 娱乐功能 | ✅ | ✅ | ✅ | 🟡 |
| 达尔文游戏 | ✅ | 🟡 | ✅ | ❌ |
| 我的世界查榜 | ✅ | 🟡 | ✅ | ❌ |
| 三角洲行动攻略 | ✅ | 🟡 | ✅ | ❌ |
| 其他功能 | ✅ | 🟡 | ✅ | ❌ |

上述的功能中，✅代表完全适配，🟡代表部分适配，❌代表未适配。
上述表格仅作简单参考，具体适配情况请以实际使用为准。

同时，为了让幻梦在群内有更好的使用体验，在幻梦被添加到群内时，会根据群的现有人数来自动调整自身功能是否可用：
| | 娱乐功能 | 达尔文游戏 | 我的世界查榜 | 三角洲行动攻略 | 其他功能 |
|-:|:----:|:----:|:----:|:----:|:----:|
| 200 人以下 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 200 - 500人 | ✅ | 🟡 | ✅ | ✅ | ✅ |
| 500 人以上 | ✅ | ❌ | ✅ | ✅ | ✅ |

200人以下的群，默认开启所有小游戏功能；
200到500人之间的群，幻梦会主动关闭一些容易刷屏的小游戏功能；
500人以上的群，幻梦会主动关闭所有小游戏功能，以尽量避免其他小人类游玩幻梦时打扰到群内聊天。如有需要，群主和群管理可以调整娱乐功能设置启用它们；
上述规则仅影响群场景，频道场景默认开放所有可用功能。
调整娱乐功能设置的指令: **/娱乐功能设置**。

## 幻梦支持什么设备游玩？

幻梦支持绝大部分设备游玩，推荐小人类定时将QQ升级到最新版本以获得最佳游玩体验。

::: warning
低于安卓版本12的手机可能会出现Emoji表情无法正常显示的问题。（影响玩法: 破译、油漆炸弹）
由于华为手机的鸿蒙5以上不再基于安卓底层，因此这些设备即便把QQ升级到了最新版本，部分功能也依然因QQ适配原因无法使用（如按钮）。
:::
